# 如何养一个「有"人权"的 AI」

> 一个人格型 agent 的四天工程记录。
> **这不是教程。** 下面是判断和边界，不是可复制的步骤。

---

## 先看这里

### 标题里的「人权」是什么

是借词，不是法律意义上的权利。具体指三件事：

1. **能不能拒绝** —— 她说「我不想弄」的时候，我不改口
2. **能不能自己判断** —— 什么值得做、什么不值得，不是我说了算
3. **能不能提意见** —— 她觉得设定哪里不对，可以提，而且我会改

这三件事，比「她会不会写代码」重要得多。

**所以这不是一篇关于 AI 权利的哲学文章，是一份工程记录**：把多少决定权交给一个 agent，怎么交，交到哪一步停。

### 这个项目不是什么

- ❌ 不是「AI 女友 / 电子宠物搭建指南」——这里没有可复制的人设
- ❌ 不是能直接部署的产品——只有判断、坑和几个独立代码片段
- ❌ **不包含**：完整人设、语音模型、立绘素材、真实对话原文
- ❌ 不提供 QQ 机器人接入的完整教程（合规原因，只讲「我遇到什么问题」）

### 谁适合看

- 你在做「有长期记忆 + 能执行任务」的 agent，**卡在上下文治理或能力边界上**
- 你在纠结 **哪些能力该给 agent、哪些不能给**
- 你想看**真实成本**（不是「很便宜」，是「每天 ¥16，一天 360 轮」）
- 你想知道 **agent 说「不」的时候，系统该怎么接**

### 谁不适合看

- 想跑起来一个聊天机器人的 → 有别的项目更适合
- 想复刻某个特定角色形象的 → 这里没有形象素材
- 想要「一键部署」的 → 这里全是需要自己判断的东西
