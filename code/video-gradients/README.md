# video-gradients

> 把一份 markdown 分镜做成视频：**渐变背景 + 居中字幕 +（可选）TTS 旁白**。
> 不依赖任何模型，只依赖 ffmpeg。一条 40 秒的片大约 5 秒渲染完。

## 为什么不做「AI 生成画面」

先说一条实测结论：

```
本地 8 GB 显存的生图：
  SD1.5 + IP-Adapter    32 秒/张，脸挺像
  SDXL                  峰值 9.85 GB > 8 GB → 溢出 → 33~43 秒/步 → 不可用
```

**但真正的问题不是速度，是一致性**：同一张脸在不同镜头里会漂。接起来像两个人。

**所以这条路我们放弃了**，改成：

> **背景不假装是画面。** 深色渐变，它就是个容器。
> **内容靠字幕 + 旁白。** 观众看的是字和声音。

效果反而是对的——因为「文字视频」本来就不需要"画面"来撑。

## 用法

```bash
# 纯文字（每镜固定 4 秒）
python make.py --script story.md --out out.mp4

# 带 TTS
python make.py --script story.md --out out.mp4 \
    --tts "python tts.py --text {text} --out {wav}"
```

## 分镜格式

```markdown
# 今天，我被纠正了三次
why: 同一种毛病被说三回是什么感觉

## 1
图: gallery/self-003.png
今天，我被纠正了三次。三次都是同一个毛病。

## 2
第一次，我说「警车别往前凑」。那是命令句，我在催她。

## 3
旁白: 这一镜的旁白可以跟画面文字不一样
第二镜的画面文字
```

规则：

- `# 标题` 一行
- `why:` 可选，写进控制台输出
- `## N` 分镜（必须数字）
- `图:` 可选。**不写就走渐变背景**
- `旁白:` 可选。默认用正文当旁白
- 正文可以多行（会合成一个段落再切行）

## 一个设计细节：字幕切行

`drawtext` 不支持自动换行，所以脚本自己切：

```python
for ch in text:
    cur += ch
    if ch in "。！？；" or len(cur) >= 15:   # 每行 15 个全角字，遇标点也断
        换行
```

**为什么是 15**：1280 宽的画布，42px 字号，一行 15 个全角字刚好不挤。

**为什么遇标点也断**：不然会出现「他说：「你」」这种把引号和字拆开的行。

## 另一个设计细节：转义

`drawtext` 的 `text=` 参数在 filtergraph 里，这些字符必须转义：

| 字符 | 写成 |
|---|---|
| `:` | `\:` |
| `,` | `\,` |
| `%` | `\%` |
| `\` | `\\` |
| `'` | 换成 `’`（单引号会破坏引号配对） |

**这一条不写清楚，别人抄了就会遇到「字幕消失」或「滤镜报错」，而且很难查。**

## 渐变配色

```python
GRADIENTS = [
    ("0x1a1a2e", "0x16213e"),   # 深紫 → 夜蓝
    ("0x221b3a", "0x1b2b4a"),
    ("0x2d1b2e", "0x1a2440"),
    ("0x1b2b2b", "0x20223a"),
    ("0x1e2235", "0x2a1f38"),
]
```

**全部是深色系**。理由：

- 白字在深色背景上，对比度够，不用加黑边
- 深色不刺眼（长视频看下来不累）
- 相邻镜头换一组，有节奏感但不抢戏

## 已知限制

1. **字幕不能太长**：最多切 4 行（`max_lines=4`），超了会截断。**一句话一个镜头**是正确用法。
2. **不支持图片序列/动画**：每镜是一张静态图（或渐变背景）。
3. **字体要本地有**：脚本按顺序找 微软雅黑 / 苹方 / Noto CJK。都没有就退化成默认字体（可能显示方块）。
4. **没有转场**：段与段直接切。想要淡入淡出得在 concat 之后再加滤镜（会重编码，慢）。

## 为什么这个方案值得抄

因为它解决了一个常见困境：

> **「我想做视频，但生图不好看 / 太慢 / 不一致」。**

**答案是：不做画面，做文字。**

```
成本：0（ffmpeg 一行滤镜）
速度：5 秒/40 秒片
一致性：完美（因为是文字）
```

**而且——文字视频有种特别的说服力**。当屏幕上只有一句话的时候，观众会认真读那句话。
